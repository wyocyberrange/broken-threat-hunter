# IT Automation: Python Debugging Lab

Welcome to the server monitoring debugging challenge! In the real world, IT professionals rarely write automation scripts entirely from scratch. More often, you will inherit broken or incomplete code and need to figure out why it's failing. 

## 🛑 The Scenario
The script in this repository, `server_check.py`, is designed to verify the uptime of our critical infrastructure by sending HTTP requests to a list of servers. However, the previous system administrator left it in a non-working state. It is currently riddled with syntax errors, typos, and logic flaws.

## 🎯 Your Mission
Your task is to locate the bugs and patch them so the script runs flawlessly and accurately reports the status of the websites. There are exactly **8 bugs** hiding in the code. 

### Prerequisites
Before you begin, ensure you have Python installed on your machine and know how to install external packages.
